About this mockup. Single self-contained HTML file — no backend, no network calls, no data leaves the page. Screens imitate a consumer complaint portal, an internal routing console and a company response portal so the routing concept can be demonstrated end-to-end. Visual language follows the publicly documented CFPB design system (green #20aa3f, navy #254b87, Source Sans 3); the seal is a placeholder marked MOCK, never the real seal.

การจำแนกหมวดในหน้าคอนโซลใช้ตัวจำลองแบบคำสำคัญ (client-side) ที่เลียนพฤติกรรมโมเดลจริง เพื่อให้เดโมทำงานได้แบบออฟไลน์ — โมเดลจริง TF-IDF + Logistic Regression รันอยู่ที่แอป Streamlit ของโครงงาน · ตัวเลข accuracy 0.877 / macro-F1 0.730 / threshold 0.60 เป็นค่าจริงจาก model_meta.json · ชื่อบริษัทและเลขเคสทั้งหมดสมมติขึ้น
